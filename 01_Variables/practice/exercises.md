# Exercises

1. **Easy**: Complete a warm-up script using the current module concept.
   - Completion criteria: Script runs and matches expected output.
2. **Easy**: Modify input values and explain behavior change.
   - Completion criteria: Submit 3 inputs and outputs.
3. **Medium**: Combine this module with one previous module and handle one edge case.
   - Completion criteria: Includes input validation and edge-case handling.

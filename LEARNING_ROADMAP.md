# Python Learning Roadmap (Beginner → Advanced)

## Scope and target outcome
This repository follows a **mixed track** (automation + scripting + problem-solving + software engineering practices).

By completion, you should be able to:
- Build Python scripts and CLI tools for daily automation.
- Design structured Python programs using functions, OOP, and modules.
- Write reliable code with tests, typing, and logging.
- Profile and improve performance.
- Package and share reusable Python projects.

## Level 1 — Foundations (Modules 01–06)
Prerequisite: none

### Outcomes
- Use variables, conditions, loops, lists, dictionaries, and functions confidently.
- Trace and debug beginner-level scripts.
- Solve small tasks using combinations of 2–3 basic topics.

### Ready-to-move-on checklist
- [ ] Can explain difference between mutable and immutable basics.
- [ ] Can write branching and looping logic without syntax support.
- [ ] Can build reusable functions with parameters and return values.
- [ ] Can solve at least 12 foundational exercises (Easy+Medium).
- [ ] Can complete 1 beginner mini project.

## Level 2 — Intermediate (Modules 07–15)
Prerequisite: complete Level 1 checklist

### Outcomes
- Work with text/data transformations and files.
- Handle errors robustly and structure code into packages.
- Build small CLI apps with clean code and reusable components.

### Ready-to-move-on checklist
- [ ] Can read/write files and handle exceptions intentionally.
- [ ] Can use comprehensions, iterators, and generators correctly.
- [ ] Can design basic classes with encapsulation.
- [ ] Can manage dependencies in virtual environments.
- [ ] Can complete the intermediate CLI milestone.

## Level 3 — Advanced (Modules 16–24)
Prerequisite: complete Level 2 checklist

### Outcomes
- Use decorators, context managers, typing, testing, and logging in production-style code.
- Diagnose issues via debugging/profiling.
- Apply concurrency basics (threading and async).
- Package and validate an advanced capstone project.

### Ready-to-move-on checklist
- [ ] Can add type hints and tests to an existing module.
- [ ] Can instrument logs for observability and debugging.
- [ ] Can profile and optimize at least one bottleneck.
- [ ] Can apply threading or async to a practical scenario.
- [ ] Can deliver the advanced capstone in staged milestones.

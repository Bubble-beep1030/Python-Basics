# Intermediate Applied Exercises (Combine 2–3 Concepts)

1. **String + Dictionary + File Handling**
   - Read a text file and output top 10 frequent words.
   - Difficulty: Medium
   - Completion criteria: handles missing file and punctuation cleanup.

2. **OOP + Exceptions + Modules**
   - Build a reusable `TaskManager` class with add/remove/list operations.
   - Difficulty: Medium
   - Completion criteria: packaged into multiple files with safe error handling.

3. **Comprehensions + Iterators + Sets**
   - Stream numbers and return de-duplicated transformed values.
   - Difficulty: Medium
   - Completion criteria: generator-based pipeline and deterministic output.

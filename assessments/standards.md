# Practice and Assessment Standards

## Difficulty labels
- **Easy**: single concept, predictable input.
- **Medium**: combines 2–3 concepts or edge-case handling.
- **Hard**: production-style constraints (used in advanced modules/projects).

## Completion criteria for every exercise
1. Correct output for provided scenarios.
2. Handles at least one edge case.
3. Handles one invalid input safely.
4. Includes a short reflection: what failed first and how it was fixed.

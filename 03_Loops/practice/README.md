# Practice Set

Each exercise includes:
- **Difficulty**: Easy / Medium
- **Completion criteria**: Exact behavior requirements listed per exercise

## Exercises
1. Easy: complete the warm-up exercise and verify expected output.
2. Easy: modify input values and explain output changes.
3. Medium: solve a scenario with one edge case and one invalid-input case.

## Definition of done
- Program runs without errors.
- Handles the listed edge case.
- Output matches expected behavior.
